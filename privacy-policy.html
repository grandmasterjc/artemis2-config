Privacy Policy

Last updated: April 9, 2026

Artemis II Tracker ("the App") is developed by Bit Factory. This policy describes how the App handles your information.

Data We Collect

The App does not collect, store, or transmit any personal data. Specifically:

  • No account or login is required
  • No personal information (name, email, location) is requested or stored
  • No advertising identifiers (IDFA) are collected
  • No cookies are used

Website Analytics

The website at artemistracker.app uses Cloudflare Web Analytics to count page views. It sets no cookies, uses no client-side state, and does not fingerprint visitors or follow them across sites. We see aggregate counts of pages viewed and referring sites, nothing that identifies you. This section covers the website only; the sections below describe the apps.

Analytics

The App uses Google Firebase Analytics to collect anonymous usage data. This helps us understand how the App is used and improve it. The data collected includes:

  • App opens and screen views
  • Feature usage (e.g., which screens are visited most)
  • Purchase events (product type only, no payment details)
  • Device type and operating system version
  • Approximate location (country/region level, derived from IP address)

This data is anonymous and cannot be used to identify you personally. No Advertising Identifier (IDFA) is collected, and no data is shared with advertisers. You can learn more about Google's data practices at Google Privacy Policy.

Network Requests

The App makes network requests to the following public services to display mission data:

  • NASA Open APIs (api.nasa.gov) — Astronomy Picture of the Day, space weather data
  • Launch Library 2 (ll.thespacedevs.com) — Launch date and status
  • NASA AROW (nasa.gov) — Real-time Orion telemetry (when active during the mission)
  • Community Orbit API (artemis.cdnspace.ca) — Orbital position data derived from JPL Horizons
  • RSS feeds — News from NASA, Spaceflight Now, Ars Technica, NASASpaceflight, Space.com
  • GitHub (raw.githubusercontent.com) — App configuration file
  • Google Firebase (app-analytics-services.com) — Anonymous analytics data

Mission data requests contain no personal information. Only publicly available data is retrieved.

Local Storage

The App stores your preferences (unit system, notification settings) locally on your device using UserDefaults. This data never leaves your device.

Children's Privacy

The App does not knowingly collect any personal information from anyone, including children under 13.
